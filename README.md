I build **CML (Continuity Markup Language)** — architecture for preserving accepted state across multi-step execution, recovery, handoff, and external observation.

> Human-led, AI-assisted, evidence-bound. I separate implementation results, observed behavior, hypotheses, and unresolved questions.

### Start Here

- **CML-Trust** — Alpha validation tooling. Records observations without mutating canonical state.
- **Work Record** — Public evidence-bound record: journals, standards, validation, HOLD/BLOCKED with exact hashes.
- **Reference Compiler** — Reference impl for invariants, locks, stale-projection rejection.
- **Agent Boundary Check** — Canary tooling for what AI agents can actually read/write/exec.
